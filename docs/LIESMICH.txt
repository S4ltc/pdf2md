pdf2md – Bücher, Normen und Dokumente in Markdown umwandeln
===========================================================

Start
  Windows 10/11 (64 Bit): pdf2md.exe in einen eigenen Ordner legen (zum Beispiel Dokumente\pdf2md, nicht
    "Programme") und doppelklicken. Daneben entstehen die Ordner Eingang, Fertig, Prüfen, Sicherung sowie
    Protokoll.csv und Einstellungen.json. Die Anzeige nutzt Microsoft Edge WebView2 (unter Windows 10/11 vorhanden).
  macOS (Vorschau): pdf2md.app zum Beispiel nach "Programme" ziehen und öffnen. Die Ordner entstehen in
    Dokumente/pdf2md.
  Linux (Vorschau, x86_64): den Ordner pdf2md entpacken und darin pdf2md starten. Die Ordner entstehen im
    Dokumente-Ordner unter pdf2md.
  "Vorschau" heißt: das Programm wird bei jedem Build auf GitHub automatisch gestartet und geprüft, auf echten
  Mac- und Linux-Rechnern aber noch nicht von Hand getestet. Rückmeldungen sind willkommen.

Warnung beim ersten Start
  Windows: Die Datei ist nicht digital signiert. SmartScreen zeigt "Der Computer wurde durch Windows geschützt":
    "Weitere Informationen" -> "Trotzdem ausführen".
  macOS: Die App ist nicht notarisiert. Nach dem ersten Öffnungsversuch: Systemeinstellungen -> Datenschutz &
    Sicherheit -> bei pdf2md "Dennoch öffnen".
  Linux: Fehlen Bibliotheken für die Anzeige (Qt), meldet sich das Programm im Terminal; meist hilft das Paket
    libxcb-cursor0 (Debian/Ubuntu) bzw. xcb-util-cursor (Fedora).

Bedienung
  "Hinzufügen …" oder Dateien ins Fenster ziehen (sie werden nach Eingang kopiert), dann "Starten".
  Ergebnisse: Fertig (Titel, Autor, Jahr gefunden) oder Prüfen (Angaben im Kopfblock der .md ergänzen, dann
  erneut "Starten"). Werkzeuge: Rückgängig, Namen reparieren, Text erneuern, Literaturliste exportieren (BibTeX für
  Citavi, Zotero, LaTeX) – jeweils mit Vorschau. Zitierstil (IEEE, APA 7, DIN ISO 690): Einstellungen.

Updates
  Oben im Fenster steht die Versionsnummer; gibt es eine neuere, erscheint "Version … verfügbar" (Klick öffnet die
  Download-Seite). Zum Aktualisieren nur das Programm ersetzen (pdf2md.exe, pdf2md.app bzw. den Ordner pdf2md),
  die Ordner mit den Dateien und Einstellungen.json bleiben. Danach Werkzeuge -> "Text erneuern".

Datenschutz
  Alles läuft auf dem eigenen Rechner. Nur wenn Angaben fehlen bzw. für die Quellenangabe wird online nachgeschlagen:
  gesendet wird ausschließlich die DOI oder ISBN an Crossref und die Deutsche Nationalbibliothek, ohne Dateiinhalt,
  Dateinamen oder persönliche Angaben. Abschalten: Einstellungen -> Online-Abgleich. Beim Start fragt das Fenster
  GitHub nach der neuesten Version (dabei sieht GitHub die IP-Adresse); abschalten: Einstellungen -> Nach Updates
  suchen. Keine Telemetrie.

Wichtig beim Zitieren
  Zitate, Zahlen, Formeln und Tabellenwerte immer im Original-PDF prüfen. Seitenangaben nur aus Markern mit
  gedruckter Seitenzahl übernehmen: <!-- Seite 197 (PDF 206) --> heißt "S. 197".
